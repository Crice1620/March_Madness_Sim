🏀 NCAA Men's Basketball Simulator & Analytics Hub
An interactive web application built with R Shiny that simulates NCAA Men's Basketball matchups, models tournament outcomes, and maps team playing styles using predictive machine learning.

🔗 Live Application: [crice1620.shinyapps.io/March_Madness_Sim]([url](https://crice1620.shinyapps.io/March_Madness_Sim/))

🌟 Application Features
Rankings & Net Ratings: View comprehensive offensive, defensive, and net efficiency ratings for D1 teams. Ratings reflect predicted scoring margin metrics against an average D1 opponent on a neutral court, with dynamic filtering by conference.

Game Simulator: Run head-to-head matchup simulations between any two teams to predict final scores and outcome probabilities.

Today's Games: Access real-time matchup predictions and analytics for daily slate games.

Team DNA & Style Mapping: Explore team playing style clusters powered by Self-Organizing Maps (SOM) and U-Matrix visualization models.

Player Analytics: Inspect individual roster contributions and statistical performance breakdowns across teams.

Region Simulator: Simulate full tournament brackets and regional paths to evaluate March Madness odds.

Model Info: Transparency tab detailing feature inputs, underlying XGBoost logic, and performance evaluations.

🛠️ Built With
Frontend/UI: R Shiny, custom CSS styling

Predictive Modeling: XGBoost (Margin/Efficiency modeling), Self-Organizing Maps (kohonen for style clustering)

Data Pipelines & Viz: tidyverse, ggplot2, dynamic HTML data tables
